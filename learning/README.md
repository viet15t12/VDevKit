
# Learning

Thư mục `learning` chứa code được viết trong quá trình **học một ngôn ngữ, framework, thư viện, giao thức hoặc công nghệ mới**.

Đây là khu vực dành cho thử nghiệm và ghi lại quá trình học thông qua code.

## Nội dung

Nội dung có thể liên quan đến:

* Programming languages
* Frameworks
* Libraries
* Databases
* Operating Systems
* Networking
* APIs
* DevOps
* Cloud
* System Administration

Ví dụ các công nghệ có thể xuất hiện:

* Python
* C / C++
* Go
* SQL
* PostgreSQL
* Linux
* Git
* Networking

## Mục tiêu

Thư mục này được sử dụng để:

* Thử nghiệm syntax và API.
* Viết code minh hoạ kiến thức mới.
* Lưu lại các ví dụ thực hành.
* So sánh cách triển khai giữa các công nghệ.
* Xây dựng các mini project phục vụ việc học.

## Lưu ý

Code trong `learning` không nhất thiết được tối ưu hoặc hoàn thiện.

Một số đoạn code được giữ lại nhằm thể hiện quá trình học và thử nghiệm thay vì đại diện cho cách triển khai tốt nhất trong production.
