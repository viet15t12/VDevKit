
# Tools

Thư mục `tools` chứa các **chương trình, utility và công cụ nhỏ** được phát triển để hỗ trợ học tập, quản trị hệ thống, networking hoặc các tác vụ kỹ thuật khác.

Khác với `scripts`, các nội dung trong thư mục này thường có logic hoặc cấu trúc chương trình lớn hơn một script đơn giản.

## Nội dung

Các tool có thể bao gồm:

* CLI utilities
* Network utilities
* System utilities
* File processing tools
* Developer tools
* Automation tools
* Experimental tools

Các công cụ có thể được viết bằng nhiều ngôn ngữ khác nhau như:

* Python
* Go
* C
* C++
* Shell

## Mục tiêu

Thư mục này được sử dụng để:

* Thử nghiệm ý tưởng.
* Xây dựng công cụ phục vụ nhu cầu cá nhân.
* Thực hành thiết kế chương trình.
* Tái sử dụng các utility hữu ích.
* Thực hành CLI và system programming.

## Trạng thái

Một số tool có thể chỉ là prototype hoặc project thử nghiệm và chưa được thiết kế để sử dụng trong production.
