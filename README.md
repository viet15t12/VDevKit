
# VDevKit

**VDevKit** là kho lưu trữ cá nhân tập hợp code, bài luyện tập, script tự động hoá, công cụ nhỏ và tài liệu kỹ thuật trong quá trình học tập và phát triển kỹ năng.

Repository này chủ yếu phục vụ việc **học tập, thực hành và lưu trữ các tài nguyên có thể tái sử dụng**, thay vì là một sản phẩm phần mềm duy nhất.

## Nội dung

VDevKit được tổ chức thành các nhóm nội dung chính:

* **scripts** — các script hỗ trợ tự động hoá công việc.
* **tools** — các chương trình và tiện ích nhỏ.
* **practice** — code luyện thuật toán và giải bài tập.
* **learning** — code được viết trong quá trình học công nghệ mới.
* **docs** — ghi chú và tài liệu kỹ thuật.

## Cấu trúc repository

```text
VDevKit/
├── scripts/
├── tools/
├── practice/
├── learning/
├── docs/
└── README.md
```

Mỗi thư mục có `README.md` riêng để mô tả mục đích và cách tổ chức nội dung.

## Mục tiêu

VDevKit được xây dựng nhằm:

1. Lưu lại quá trình học tập và thực hành lập trình.
2. Quản lý các bài luyện thuật toán tại một nơi thống nhất.
3. Lưu trữ script và công cụ phục vụ tự động hoá.
4. Tập hợp các đoạn code có khả năng tái sử dụng.
5. Lưu giữ ghi chú và tài liệu kỹ thuật.
6. Theo dõi quá trình phát triển kỹ năng theo thời gian.
