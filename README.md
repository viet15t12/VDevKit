# VDevKit

Kho lưu trữ cá nhân chứa code trong quá trình học tập, code luyện tập thuật toán, các script/tool tự động hoá công việc nhỏ, cùng tài liệu liên quan đến lập trình, CCNA và LPI.

## Mục đích

- Lưu lại code viết trong quá trình học các môn/công nghệ mới
- Lưu code luyện tập thuật toán, thi đấu lập trình
- Chứa các script `.sh`, `.bat` và tool nhỏ dạng dòng lệnh, chủ yếu để hỗ trợ tự động hoá một số công việc cá nhân
- Lưu tài liệu (`.md`, `.pdf`, `.typ`, `.tex`) liên quan đến lập trình, CCNA, LPI
