# 7. Quy trình luyện mỗi bài

```text
Đọc đề
   ↓
Tự tìm hướng giải
   ↓
Code
   ↓
Accepted?
 ┌───────┴───────┐
Yes              No
 ↓                ↓
Review       Debug / suy nghĩ
                  ↓
              Xem hint
                  ↓
             Xem editorial
                  ↓
              Code lại
```

---

# 8. Nguyên tắc quan trọng

### 1. Không xem Editorial quá sớm

Cố gắng tự suy nghĩ trước.

Nếu bí:

```text
Hint
↓
Idea
↓
Editorial
↓
Solution Code
```

Không nên đọc code người khác ngay từ đầu.

---

### 2. Upsolve sau Contest

Sau mỗi contest:

```text
Solved
+
Almost solved
+
Couldn't solve
```

Hãy làm lại các bài chưa giải được.

Đây thường là những bài giúp tăng trình nhanh nhất.

---

### 3. Ghi lại Pattern

Ví dụ:

```text
Range Sum
→ Prefix Sum

Monotonic Answer
→ Binary Search

Shortest unweighted path
→ BFS

Connectivity
→ DFS / DSU

Range Query
→ Fenwick / Segment Tree
```
