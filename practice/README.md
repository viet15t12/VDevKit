
# Practice

Thư mục `practice` chứa code dùng để **luyện tập lập trình, thuật toán và kỹ năng giải quyết vấn đề**.

## Nội dung

Các bài tập có thể đến từ:

* LeetCode
* Codeforces
* HackerRank
* Codewars
* Exercism
* CodeLearn
* Bài tập trên lớp
* Bài tập tự luyện

## Chủ đề

Các bài luyện tập có thể liên quan đến:

* Array
* String
* Hash Table
* Sorting
* Searching
* Recursion
* Dynamic Programming
* Graph
* Tree
* Greedy
* Mathematics
* Data Structures
* Algorithms

## Ngôn ngữ

Các lời giải có thể được viết bằng:

* Python
* C
* C++
* Go
* Các ngôn ngữ khác phục vụ quá trình học tập

## Mục tiêu

Thư mục này tập trung vào:

* Cải thiện tư duy thuật toán.
* Luyện khả năng phân tích bài toán.
* Học Data Structures & Algorithms.
* So sánh cách triển khai giữa các ngôn ngữ.
* Theo dõi quá trình luyện problem solving.

Các lời giải ưu tiên tính dễ hiểu trước khi tối ưu hoá sâu.
