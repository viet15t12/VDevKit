
# Docs

Thư mục `docs` chứa **ghi chú, tài liệu kỹ thuật và nội dung tham khảo** được tạo trong quá trình học tập.

## Nội dung

Tài liệu có thể liên quan đến:

* Programming
* Linux
* System Administration
* Computer Networking
* Cisco CCNA
* LPI
* Database
* Git
* DevOps
* Cloud
* Software Development

Các định dạng tài liệu có thể bao gồm:

* Markdown (`.md`)
* Typst (`.typ`)
* LaTeX (`.tex`)
* PDF (`.pdf`)
* Diagram
* Source document khác

## Mục tiêu

Thư mục này được sử dụng để:

* Hệ thống hoá kiến thức.
* Lưu ghi chú kỹ thuật.
* Tổng hợp command và configuration.
* Viết tài liệu học tập.
* Lưu các tài liệu tham khảo do cá nhân biên soạn.

## Lưu ý

Nội dung trong thư mục này được xây dựng chủ yếu cho mục đích học tập và có thể được chỉnh sửa khi kiến thức hoặc công nghệ liên quan thay đổi.
