
# Scripts

Thư mục `scripts` chứa các script được sử dụng để **tự động hoá các tác vụ lặp lại hoặc đơn giản hoá các thao tác thường xuyên**.

## Nội dung

Script trong thư mục này có thể được viết bằng:

* Bash / Shell
* PowerShell
* Batch
* Python
* Các ngôn ngữ scripting khác khi cần thiết

Một số nhóm tác vụ thường gặp:

* Quản lý file và thư mục
* Xử lý dữ liệu
* Quản trị Linux
* Network utilities
* Git automation
* Backup
* Cài đặt và cấu hình môi trường
* DevOps utilities

## Nguyên tắc

Mỗi script nên:

* Có tên mô tả rõ chức năng.
* Hạn chế phụ thuộc không cần thiết.
* Có comment khi logic không rõ ràng.
* Kiểm tra input khi cần thiết.
* Tránh hard-code thông tin nhạy cảm.
* Có hướng dẫn sử dụng nếu script yêu cầu tham số đặc biệt.

## Lưu ý

Các script trong thư mục này chủ yếu được xây dựng cho mục đích học tập và sử dụng cá nhân.

Hãy đọc nội dung script trước khi chạy trên hệ thống thực tế.
